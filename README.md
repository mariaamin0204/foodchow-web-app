# 🍔 FoodChow – Online Food Ordering App

A modern, responsive full-stack food ordering web application built with React, Tailwind CSS, and Firebase.

## 🚀 Live Demo
[Click Here to View Live Project](https://foodchow-web-app.netlify.app/)

## ✨ Key Features
- 🔐 **User Authentication:** Secure Login & Signup using Firebase Auth.
- 🍕 **Dynamic Menu:** Interactive food category filtering and menu items fetched from Firestore.
- 🛒 **Real-Time Cart:** Add/remove items, quantity controller, and instant price calculation.
- 📦 **Order Management:** User orders saved directly to Cloud Firestore.
- 📱 **Fully Responsive:** Optimized for mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS / Bootstrap 5, Vite
- **Backend-as-a-Service:** Firebase (Authentication & Cloud Firestore)
- **Deployment:** Netlify / Vercel
